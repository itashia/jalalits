# مرجع API و محدودهٔ قابلیت‌ها

سال‌های جلالی ۱ تا ۳۱۷۷ پشتیبانی می‌شوند. ورودی تاریخ `YYYY/MM/DD` است. خطاهای ورودی با `InvalidDateError` گزارش می‌شوند. زمان منطقه‌ای و انتخاب ارقام محلی در هر فراخوانی تعیین می‌شوند و تنظیم سراسری وجود ندارد.

## بازه، تکرار، تقویم کاری و زبان طبیعی

در نسخهٔ فعلی فقط hook سادهٔ بازه در بستهٔ React وجود دارد. بسته‌های مستقل ranges، recurrence، business و natural هنوز منتشر یا پیاده‌سازی نشده‌اند.

## مهاجرت از Laravel Jalali

مدل تقویم، بازهٔ سال، parsing سخت‌گیرانه، ارقام، تغییرناپذیری، هفتهٔ شنبه‌محور و منطق clamp از مرجع Laravel الهام گرفته‌اند. Facade، Carbon، castهای Eloquent و helper لاراول در جاوااسکریپت وجود ندارند. سازگاری کامل همهٔ رفتارهای PHP هنوز اثبات نشده است.

## امنیت، مشارکت و رفع اشکال

برای مشارکت از commitهای Conventional Commits و Changesets استفاده کنید. زمان محلی پرش‌یافته را با ساعت معتبر همان منطقه جایگزین کنید. برای اشکال امنیتی از GitHub Security Advisories خصوصی استفاده کنید.
