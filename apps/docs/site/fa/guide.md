# شروع سریع و راهنمای فارسی

## نصب

```sh
npm install jalalits
```

بستهٔ اصلی هیچ وابستگی زمان اجرا ندارد. برای React، Zod، Temporal و توابع مرز API بسته‌های جدا نصب می‌شوند.

## مدل تاریخ و تبدیل

`PersianCalendar.toGregorian` و `PersianCalendar.fromGregorian` توابع خالص تبدیل هستند. `JalaliDateTime.create` تاریخ و زمان جلالی را با منطقهٔ زمانی صریح می‌سازد. `parse` فقط قالب دقیق `YYYY/MM/DD` را می‌پذیرد و ارقام لاتین، فارسی و عربی را می‌شناسد.

## حساب تاریخ، مقایسه و قالب‌بندی

مقادیر تغییرناپذیر هستند. جمع روز بر اساس روز تقویمی محلی انجام می‌شود؛ جمع ساعت و ثانیه زمان سپری‌شده را تغییر می‌دهد. جمع ماه در آخرین روز معتبر ماه مقصد متوقف می‌شود. مقایسه بر اساس لحظه است. قالب `Y/m/d` تاریخ جلالی می‌دهد و `F` و `l` نام فارسی ماه و روز هفته را نمایش می‌دهند.

## منطقهٔ زمانی و دقت

منطقهٔ زمانی را هنگام ساخت مقدار مشخص کنید. زمان محلی ناموجود در پرش ساعت تابستانی رد می‌شود. `Date` و `toISOString()` تنها دقت میلی‌ثانیه دارند؛ برای حفظ نانوثانیه از `epochNanoseconds` یا بستهٔ Temporal استفاده کنید.

## یکپارچه‌سازی‌ها

`@jalalits/react` پنج hook بدون UI ارائه می‌دهد و برای SSR تاریخ و ماه ورودی صریح می‌خواهد. `@jalalits/zod` با Zod 4 کار می‌کند و ورودی معتبر را به `JalaliDateTime` تبدیل می‌کند. `@jalalits/temporal` تبدیل صریح Instant و انواع Plain و Zoned را فراهم می‌کند. `@jalalits/api` برای parsing، نرمال‌سازی فرم و serialization مستقل از فریم‌ورک است.
