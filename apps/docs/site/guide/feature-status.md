# Date ranges, recurrence, business calendars, and natural language

The current package inventory contains `jalalits`, `@jalalits/react`, `@jalalits/zod`, `@jalalits/temporal`, and `@jalalits/api`. The `@jalalits/ranges`, `@jalalits/recurrence`, `@jalalits/business`, and `@jalalits/natural` packages are not implemented or exported in this release. No API or compatibility guarantee is claimed for those feature areas.

The React range hook provides minimal inclusive range state. It is not a standalone range algebra package, recurrence engine, holiday dataset, or natural-language parser.

## Performance

Run `pnpm bench` to execute the reproducible core and comparison benchmark when optional benchmark dependencies are installed. Benchmark reports must include the runtime and dependency versions; this project does not make speed claims without measurements.
