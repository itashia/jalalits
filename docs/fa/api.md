# قرارداد API هسته

`JalaliDateTime` یک مقدار تغییرناپذیر شامل یک لحظه زمانی و منطقه زمانی صریح است. `create` اجزای تاریخ جلالی را می‌گیرد و `parse` فقط قالب `YYYY/MM/DD` را می‌پذیرد. ارقام لاتین، فارسی و عربی پشتیبانی می‌شوند. تاریخ نامعتبر، سال خارج از بازهٔ ۱ تا ۳۱۷۷، زمان یا منطقهٔ زمانی نامعتبر با `InvalidDateError` گزارش می‌شود.

الگوریتم تقویم از مدل سال‌های شکست بورکوفسکی در مرجع Laravel پیروی می‌کند. جمع روز بر اساس روز تقویمی محلی و جمع ساعت/دقیقه/ثانیه بر اساس زمان سپری‌شده انجام می‌شود. جمع ماه در آخرین روز معتبر ماه مقصد متوقف می‌شود. مقایسه بر اساس لحظهٔ زمانی است و شمارهٔ روز هفته از شنبه صفر است.
